# ChatHub

ChatHub é um **aplicativo web de chat** que permite conversas online individuais ou em grupo. Com uma interface intuitiva, você pode adicionar amigos, iniciar conversas, criar grupos e interagir em tempo real. O projeto utiliza **Next.js** no frontend, **C#** no backend, e autenticação baseada em **JWT**.

---

## 📝 Funcionalidades

- Autenticação de usuários com **JWT**.
- Adição de amigos e início de conversas individuais.
- Criação de grupos de chat com múltiplos participantes.
- Envio e recebimento de mensagens em tempo real.
- Interface responsiva e moderna no **Next.js**.

---

## 🛠 Tecnologias Utilizadas

- **Frontend:** Next.js, React, Tailwind CSS (ou outra biblioteca de estilo que estiver usando)
- **Backend:** C# (.NET Core / .NET 7) com API REST
- **Autenticação:** JWT
- **Banco de Dados:** SQL Server / outro banco relacional
- **Comunicação em tempo real:** SignalR (C#) ou WebSockets
- **Gerenciamento de estado:** React Context / Zustand / Redux (dependendo da implementação)

---

## 🚀 Funcionalidades Principais

1. **Autenticação**

   - Login e cadastro de usuários
   - Proteção de rotas privadas com JWT

2. **Mensagens Individuais**

   - Adicione um amigo e abra uma conversa
   - Histórico de mensagens

3. **Grupos**

   - Crie grupos de chat
   - Adicione múltiplos participantes
   - Envio de mensagens em grupo

4. **Tempo real**
   - Notificações de novas mensagens instantâneas
   - Atualização automática de conversas
